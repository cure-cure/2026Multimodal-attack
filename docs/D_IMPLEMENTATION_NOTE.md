# D 实现与协作说明

当前第三周已交付：统一接口v2、六条模拟交接样例、图文输入界面、三模式输出、固定融合、批量读取、异常处理和交接校验。31项测试通过，均只验证软件行为，不代表真实检测效果。

## 成员边界与交接

| 成员 | 维护内容 | 与D的交接 |
| --- | --- | --- |
| A | 数据来源、分组、四类划分、真值和统一指标 | 提供清单；确认[数据用途](DATA_PROTOCOL.md)；读取D预测 |
| B | CIDER、OCR、自主视觉特征、配置及复现差异 | 按[接口v2](INTERFACE_SPEC.md)交图像证据；OCR缓存同时供C读取 |
| C | 文本规则、自主文本分类和可选LoRA | 交用户文字/OCR/组合三类分数及依据；OCR未就绪时只交用户文字分数 |
| D | 统一接口、固定与可训练融合、系统及批量输出 | 检查编号、保留缺失状态和版本、交预测给A，负责系统演示 |

所有记录以sample_id连接。不可用模块的分数为null；OCR失败不等于无文字，程序不会使用失败OCR的残留分数。完整融合缺少全部文本分数时返回证据不足，图像模式与整体风险使用不同评测目标。

## 联调顺序

1. A/B/C确认接口、标签口径和四类数据用途；当前尚无实际确认记录。
2. A交数据包v1，B/C按清单独立开发；D继续用模拟证据完成框架。
3. 第五周D接入B/C第四周v1，生成真实固定融合预测给A。
4. 第六周使用第五周稳定B/C结果，在fusion_train训练自主融合、validation选阈值，冻结版本交A。
5. A统一评测；D配合分析失败、打包及系统演示。
