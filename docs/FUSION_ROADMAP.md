# D 自主融合路线与课件核对

## 当前已实现

负责人D。`fusion.py` 的 `text_overlap` 自主计算字符二元组Jaccard；`build_feature_vector`计算风险协同启发式；`FusionEngine.fuse`实现可用证据加权融合和缺失处理。它们不等于语义模型，不证明组合风险一定被识别，也不代表已经满足“课件算法”核验。

固定基线使用配置里的固定权重和阈值，不根据正式测试效果修改。`image_only`仅使用B图像分支，`text_only`仅使用C的三类文本分数，`full`使用图像、文本及D协同特征。保留旧 `user_text_only`/`user_text_ocr`作为额外对照。图像模式的CIDER原始统计量与阈值由B配置提供，D不重新调其阈值。

## 可训练融合候选（尚未实现，须核对课件）

优先候选为自主实现逻辑回归：输入B图像风险分数、C三类文字风险分数、D协同特征和各项缺失指示；用 `p=1/(1+exp(-(w·x+b)))` 输出分数，以二元交叉熵训练，手写梯度 `Xᵀ(p-y)/N` 和参数更新，不调用现成分类器。固定随机种子、特征顺序及训练次数，保存权重、偏置、缺失处理策略、数据版本和B/C配置版本。

只在 `fusion_train` 拟合参数及缺失填充值，在 `validation` 选择判定阈值；不因模块缺失自动判正常。缺失指示作为特征保留，完全没有有效证据时拒绝判断。与固定融合用相同数据和冻结上游版本比较，由A统一统计准确率、召回率、F1及误报/漏报。

选择理由：分数维度少、CPU可训练、参数和证据贡献易解释，适合现有接口。这是工程候选，未经课件核对不得写成“课件已确认”。当前文件夹没有课件；待补充具体课件标题、章节、页码或老师确认。如果课件不包含逻辑回归，则改选课件确实讲授的可训练算法，并记录变更。不得用本文候选代替课程红线要求。
