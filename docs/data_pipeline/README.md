\# A 侧数据管线

本目录介绍项目 A 侧的数据准备流程，包括公开数据的离线核验、来源与许可记录、图文样本整理、相关样本分组和下游清单导出。



\## 数据集范围

\- HoliSafe-Bench：当前用于课程派生的图文整体安全风险实验。

\- JailBreakV-28K：可选的外部攻击挑战集候选，不是当前主实验的必要依赖。

\- CIDER：图像扰动分析候选资源，尚未作为正式标注数据集使用。



\## 数据与标签边界

数据集来源标签不等于本项目模型的预测结果。当前数据不能直接支持越狱意图、提示注入或图像对抗检测准确率等结论；未知标签应

保留为空，不当作负例。
